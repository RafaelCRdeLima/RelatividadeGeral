Programas do curso

Todos os programas citados na apostila, prontos para baixar e executar. Cada seção de Resolução numérica do texto aponta para um arquivo desta página; os números impressos nas caixas de saída da apostila são exatamente o que estes scripts produzem quando executados.

Baixar todos (.zip) Ver no GitHub ↗

Como executar os arquivos .py

Os scripts rodam sem argumentos e não dependem uns dos outros. Os que geram figuras escrevem em uma pasta figuras/ criada ao lado da pasta do script. 

python3 -m pip install numpy scipy matplotlib
python3 cap07_curvatura.py

Como executar os arquivos .wl

São verificações simbólicas em Wolfram Language. Abra no Mathematica ou execute pelo terminal com o Wolfram Engine, gratuito para uso pessoal. 

wolframscript -file cap07_curvatura_simbolico.wl

Capítulo 2 · Relatividade especial

cap02_boosts.py Python

Verifica numericamente que ΛTηΛ = η, que a composição de dois boosts colineares segue a fórmula relativística de adição de velocidades e que a rapidez é aditiva.

Imprime resíduos da ordem de 10−16.

Baixar
cap02_tempo_proprio.py Python

Tempo próprio do gêmeo viajante para um perfil de velocidade suave, v(t) = v₀ sen(πt/T), por quadratura adaptativa. Mostra por que não se pode usar o fator de Lorentz da velocidade média.

Gera cap02_tempo_proprio_numerico.pdf.

Baixar
cap02_figuras.py Python

Gera as figuras do capítulo: diagrama de simultaneidade, paradoxo dos gêmeos com marcas de tempo próprio e cone de luz.

Prova simbólica, para v₁ e v₂ arbitrários, da invariância do intervalo, da composição de boosts e da aditividade da rapidez. Deriva a fórmula de adição de velocidades por eliminação direta.

Contém a máquina genérica christoffel / riemann / invariantes, reutilizável em qualquer métrica. Gera 2 PDFs.

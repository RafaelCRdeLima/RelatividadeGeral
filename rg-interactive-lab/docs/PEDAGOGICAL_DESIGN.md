# Desenho pedagógico

As doze atividades formam quatro blocos:

1. objeto geométrico, componentes e mudança de base;
2. one-forms, emparelhamento e base dual;
3. gramática de índices, validade, produto e contração;
4. métrica, operadores musicais e desafio integrador.

Cada etapa segue introdução curta, manipulação, pergunta, feedback e escolha de
continuidade. A questão só é liberada após interações mínimas. Erros preservam
tentativas e oferecem pista, refação ou avanço explícito sem domínio.

As representações usam uma linguagem visual consistente: violeta para vetores,
laranja para covetores ou índices mudos, ciano para bases e transformações e
verde/vermelho para validação acompanhada de texto. A base dual é mostrada como
famílias de níveis, não como uma segunda seta, para reforçar a distinção entre V
e V*.

A pontuação é diagnóstica. Uma atividade só conta como dominada após resposta
correta; avançar depois de erro preserva o percurso, mas não concede domínio.
Competências são agregadas a partir das atividades que as exercitam.
